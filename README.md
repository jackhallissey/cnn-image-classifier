# Laundry basket vs showerhead image classifier

This assessment is about creating a neural network image classifier. The classes used are a laundry basket and a showerhead, as they are everyday objects not included in the dataset later used for transfer learning.

This repo contains:
- A dataset of 300 laundry basket and 300 showerhead images, split into training, validation and test sets
- A training notebook in which I build a series of models
- A demo notebook in which I highlight the strengths and weaknesses of the best classifier

The best classifier is saved to a file in the training notebook, which is then loaded by the demo notebook. However, this file is not included due to size limits.

This is an assessment for [CS3515 (Hands-On Machine Learning)](https://www.cs.ucc.ie/~dgb/courses/homl.html).
